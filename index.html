Zivo酒馆隐私政策

更新日期：2026年11月10日
生效日期：2026年11月10日

运营主体：ZivoX
适用产品：Zivo酒馆 Android 单机版（0.2.0）
应用包名：com.zivo.zivotavern

本版本提供本机机器人卡牌对战，无需注册账号或联网游玩。游戏在您的设备上保存昵称、本地随机身份标识及偏好设置，不将这些数据上传给我们。请阅读下文了解具体处理方式及您的选择。

一、适用范围

本政策由 ZivoX（以下简称“我们”）制定，适用于上述 Android 单机版游戏及您通过本政策所列邮箱向我们提出的咨询或隐私请求。其他联机版本、小游戏版本及第三方平台服务的数据处理不包含在本版本范围内。

当前单机版未接入账号登录、广告、支付、行为统计、第三方崩溃上报、TapTap 登录或实名认证 SDK。若后续版本增加相关服务，我们将先更新相应说明，并依法履行告知、同意等义务。

二、我们如何处理信息

昵称：用于在单机对局中显示您的玩家名称，保存在本机。您可以使用默认昵称，也可以在首页修改；请勿将真实姓名、手机号码等私人信息作为昵称。

本地随机身份标识：游戏首次运行时随机生成，用于本机玩家与对局身份识别。它不由 IMEI、Android ID、OAID、MAC 地址等设备标识生成，不上传至服务器。

偏好设置：音乐、音效、音量、震动等设置，以及您已确认的隐私政策版本记录保存在本机，用于记住您的选择并在政策变化时重新提示。

对局信息：手牌、行动、机器人状态及结算信息仅在本机运行本场游戏时处理；退出本场后不保存可恢复的对局进度，不提供云存档。

您主动发送的邮件：如果您联系我们，我们会收到您的发件邮箱、邮件内容及主动提供的附件，仅用于回复咨询、排查您反馈的问题或处理隐私请求。请仅提供与问题有关的必要信息，避免发送密码、身份证件等无关敏感信息。

当前单机版不请求网络访问权限，不连接游戏服务器，不自动检查更新，也不向我们上传设备信息、游戏日志或行为记录。游戏不读取通讯录、短信、通话记录、精确位置、摄像头、麦克风或您的相册内容。

三、设备权限与本地存储

本版本声明 Android 震动权限（android.permission.VIBRATE），用于出牌等操作的触觉反馈。该权限用于驱动震动，不用于读取个人信息。您可以在游戏“设置”中关闭震动，关闭后仍可正常游玩。

昵称、标识及偏好文件保存在应用私有数据目录，无需读取您的公共文件或申请相册、通讯录权限。游戏不使用 Cookie、广告标识或类似技术进行跨应用追踪。

四、信息保存与保护

游戏的本地配置在您保留应用数据期间存储于设备中。您可通过 Android 系统设置清除本应用的数据，删除本地昵称、标识和偏好；再次启动时会生成新的随机标识并恢复默认设置。卸载通常也会删除应用私有数据，系统备份或恢复功能的行为由设备系统及您的系统设置决定。

我们不在服务器保存本版本的玩家配置或对局数据。您主动发送的邮件通过联系邮箱的邮件服务处理，仅在处理请求所必需的期间保留；问题解决后删除不再必要的信息，法律另有保存要求的除外。

我们限制对客服邮件的访问，不将邮件内容用于营销；游戏配置使用系统提供的应用数据隔离机制保护。请妥善保管设备。发现与我们服务有关的信息安全事件时，我们将采取处置措施并依法履行通知义务。

五、第三方服务与信息共享

当前游戏未集成第三方个人信息收集 SDK，不出售您的个人信息，也不向广告商提供本地游戏数据。除取得您的授权、处理您主动请求所必需或法律规定的情形外，我们不向其他主体提供您的邮件内容。

您通过 TapTap 下载、浏览游戏或使用其平台功能时，平台自身的信息处理适用其向您展示的隐私政策。本单机安装包未集成 TapTap 登录或 TapPlay SDK；平台独立提供的服务与游戏内的数据处理应分别了解。

本政策网页使用 GitHub Pages 托管。浏览器访问网页时，托管服务可能处理 IP 地址、访问时间等网络请求信息，具体见 GitHub 隐私声明（https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement）。网页本身未嵌入统计脚本、广告、表单或第三方字体；浏览此网页不会向我们提交您的本地游戏数据。

六、您的管理与联系渠道

您可在游戏首页查看和修改昵称，在“设置”中管理声音与震动，在 Android 系统设置中清除应用数据。清除数据会重置本机设置，请在操作前确认。本版本无需注册账号，因此没有服务器账号或账号注销流程。

对于您通过邮件提供的信息，您可以联系我们申请查阅、复制、更正或删除，也可以撤回对后续非必要处理的授权、提出投诉或请求解释本政策。我们会在核实请求后依法处理；身份核实仅要求与请求相称的必要信息。撤回授权不影响撤回前已依法开展的处理。

七、未成年人保护

未成年人请在监护人指导下阅读本政策并合理安排游戏时间。不满十四周岁的用户如需通过邮件提供个人信息，应由监护人协助联系。若监护人认为我们通过客服邮件不当处理了未成年人的信息，可通过下方邮箱申请核实与删除。

本政策不代表游戏已提供实名认证或防沉迷功能；相关平台服务以实际发布渠道提供的功能与说明为准。

八、政策更新

如游戏功能或信息处理方式发生变化，我们会更新本政策及更新日期。涉及处理目的、信息种类或接收方等重大变化时，我们将通过版本说明、应用内提示等适当方式告知，并在法律要求时取得您的同意。本政策不会因您仅浏览网页而自动授权我们处理额外信息。
